# ValoraBTC Protocol

ValoraBTC is a **BTC liquidity routing & settlement protocol** for modern DeFi.

It is **not**:
- a wrapped BTC clone
- a Bitcoin L2

Instead, ValoraBTC is an **infrastructure coordination layer** that helps BTC liquidity move across multiple rails with transparent routing and settlement-aware rules.

## Core Idea

Bitcoin is the largest crypto asset, but it cannot directly participate in smart-contract DeFi. ValoraBTC is designed to unlock BTC utility while keeping the model clean, auditable, and conservative.

## Dual-Token Model (Clarity First)

### VLBTC — Ecosystem & Market Token
- **Fixed supply:** 21,000,000
- **Role:** presale + ecosystem growth + staking/incentives + governance (later stages)
- **Purpose:** market-facing token that captures protocol growth through usage

### VLCOR — Technical Engine Token
- **Role:** internal routing/settlement coordination and protocol mechanics
- **Supply behavior:** minted/burned in relation to BTC flows (technical asset)
- **Not marketed:** not designed for speculation; focused on validators and system integrity

## Why This Matters

Most BTC-to-DeFi solutions force users into a single trust model (custodian, signer set, or a specific L2). ValoraBTC is built to reduce this forced choice by operating as a routing and settlement layer above BTC liquidity rails.
